How this demo works Flags are evaluated on the back-end; the demo UI only explains the result.

1 · Architecture

Every flag is evaluated on the back-end. Each cell is an iframe served by the app (:3000), which holds a back-end SDK token and nothing else. The SDK keeps a copy of the flag config (polled every second) and decides each user locally; the browser receives colours and labels, never rules.

The demo UI (:3002) is not part of the pattern. It reads the live rules, asks the Unleash Playground why each user got their result, and lists change requests. For that it reuses an Admin PAT (UNLEASH_PAT), which is not recommended outside a demo.

2 · One cell, step by step

  1. The grid page tells iframe n its user and tab (postMessage); the iframe calls the app: GET /cell.json?tab=1&userId=user-07.
  2. The app looks the user up in the data team's list (config/holdout.json) and builds the Unleash context: { userId, sessionId, properties: { holdout } }.
  3. The Node SDK evaluates the flags in process, from the config it polls from /api/client/features every second: segments and constraints first, then the rollout hash, then the variant hash. No network call per user.
  4. The app returns colour, label, flag results and payload; the iframe draws them. It never sees a rule.
  5. Each evaluation fires an SDK impression event; the app forwards them to the sink in 1 s batches, which writes JSONL and, if set up, BigQuery.
  6. Separately, the demo UI sends the 25 users to the Unleash Playground in one call. Unleash answers per user and per constraint whether exclude-holdout-group let them through. A user it blocks gets an orange box and the reason (holdout=true or userId rule).

4 · Why the counts are not exact: hashing

Unleash does not count users into buckets. For each user it hashes groupId:userId (MurmurHash) to a number from 1 to 100 and lets the user in when the number is at or below the rollout %. A second hash, with a different seed, picks the variant from the weight bands. Each user is decided alone, so 20% is a long-run rate, not a quota.
